The idea of having all my data stored somewhere in the cloud (aka someone else's servers) is not appealing to me. The cloud comes with a lot of advantages (no maintenance, scalability, etc.), but also with some risk. Cloud providers are companies - and as such - they should make profit out of the data we gave to them. Whenever we give our data to any cloud provider, we are subscribing a contract that we cannot fully trust[^1][^2][^3]. Moreover, the attack surface is huge, and an issue in a single cloud service can result in a data leak with some serious consequences.

Moreover, I really enjoy Linux system administration and the technical challenges that setting up a new server brings. My current Archlinux (Desktop) setup is pretty boring (I use the same setup by 15 years) - so I decided to setup a local server using some "new" technologies I haven't experienced yet
