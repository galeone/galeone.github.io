I don't know what's going on - I always wanted to solve problems, create something and now that I have access to a tool that's able to speed up the whole design and development process... I just got bored.

I don't feel that passion of building anymore, since I'm not building at all. There's no building on letting something else build on my behalf, there's no thinking or design in prompting. There's no engineering or challenge. It's just "prompt", see the output, evaluate, adjust, repeat. What the hell is this?

I've always being "maker" - I studied topics in depth, spent hours and sleepless nights thinking about problems and solutions. I've experienced that great feeling of "this is a great idea" coming out of nowhere while doing unrelated activities, and having to rush back at my desk to write it down and implement it. That was great - it was rewarding, it was really meaningful. My brain was braining and I felt good every time I looked at what I created.

Software of any kind: ML libraries, web development tools, websites, endless scripts for linux system administration, setting up servers, creating online communities, designing database architectures and my guilty pleasure of mixing languages and technologies that I didn't know, just to experiment (mixing C with Go, learning rust just to create a backup tool, writing bots in python to automatize stuff on Amazon, ...).

Now all of this is just... gone? I can just have an idea, ask the model of the month to implement it, and wow it's there - written in no time, and with the code quality that month by month I see to increase. If I start adding guardrails, rules, and design documents before generating stuff, the model is going to generate pretty much the same thing I would have written (not really - but you got the idea).

But what the point?

The point was never going from A to B - the point has always been to have fun while going from A to B, learn something new in the meantime, and gain more savvy.

That's the point - savvy. And I (we?) are losing it.

Savvy is the fundamental idea for me - learning by doing. Doing mistakes, learn from them, repeat, and grow.

With the LLMs every time there's a mistake, I don't learn. I can spot the mistake because I have some experience (and I'm lucky of being born 34 years ago), I can pin point the mistake and let the LLM fix it.

The shitty thing here is that LLM providers (but thanks to some good old Linux sysadmin skills I create my small LLM machine locally, I'll write about it sooner or later) can steal my savvy and re-train the model with my fixes inside - so I'm not even going to see those mistakes anymore, and I can't keep my savvy trained.

So... what? I don't now - this article is mainly just a rant, humanly written, that's going to be used by some company to train some LLM and in the future used by someone else to generate something similar.
